# نسبولوجي | NASBOLOGY

تطبيق Android عربي بواجهة داكنة ولمسات بنفسجية، يبدأ بشاشة ترحيب تطلب اسم المستخدم ثم ينتقل عبر مشهد تحقق تمهيدي ومحاكاة مسح بصري، وفحص وجه حي بالكاميرا الأمامية لمدة 8 ثوانٍ، ثم استبيان قابل للتعديل من 20 سؤالًا وتقرير نهائي مصوّر.

## المراحل والميزات
- شاشة الترحيب تعرض مفهوم المختبر التفاعلي، وحقل الاسم، وزر «ابدأ الفحص»، ثم رابط صفحة المطوّر في أسفل الشاشة.
- يستخدم التطبيق نافذة Android BiometricPrompt للتحقق من وسيلة بيومترية مسجلة على الجهاز. التطبيق لا يستقبل بيانات البصمة نفسها ولا يخزنها.
- مشهد مسح بصري متحرك يعرض «جارٍ التحليل»، ثم نتيجة محاكاة يتم اختيارها عشوائيًا مرة واحدة لكل اسم مدخل وتخزينها محليًا على الجهاز؛ لا يُستخدم عنوان IP ولا تُرسل النتائج إلى خادم.
- فحص مباشر للوجه عبر CameraX مع اكتشاف وجود وجه محليًا عبر ML Kit لمدة 8 ثوانٍ. تتوقف الكاميرا بعد انتهاء المسح. لا تُلتقط صورة ثابتة ولا تُحفظ صور الوجه في التطبيق. يمكن متابعة الاستبيان إذا تعذّر منح إذن الكاميرا.
- عشرون سؤالًا أوليًا، مع إمكانية تعديل نص السؤال واستنتاج «نعم» واستنتاج «لا» وحفظها محليًا.
- صفحة خلاصة بعد كل إجابة، ثم محرك نتيجة موزون وثابت يُستخدم في شاشة النتيجة والتقرير معًا. تعرض الواجهة النسبة والتصنيف فقط دون شرح لطريقة الاحتساب.
- شاشة التقرير تعرض النتيجة أولًا، ثم قائمتين قابلتين للفتح والإغلاق لنتيجة مشهد البصمة ونتيجة مشهد الوجه، مع حركات انتقال سلسة.
- إنشاء تقرير كامل على هيئة صورة يشمل الاسم، والنتيجة النهائية، ونتيجتي المحاكاة، وتفاصيل الأسئلة والإجابات والاستنتاجات، وتوقيع «Aram Aoyal» بصفته معدّ التجربة؛ مع الحفظ والمشاركة.
- صفحة المطوّر باسم Aram Aoyal مع زر يفتح حساب Telegram دون عرض الرابط كنص.
- دعم العربية واتجاه RTL، خط IBM Plex Sans Arabic، ألوان بنفسجية، مؤثرات حركة، خيار صوت، وحفظ محلي اختياري لآخر تقرير.

## طبيعة النتائج
الأسئلة ونتائج البصمة والوجه في هذا المشروع عناصر محاكاة ترفيهية. التحقق بالبصمة لا يقرأ قالب البصمة داخل التطبيق، واكتشاف الوجه يكتشف وجود وجه أمام الكاميرا ولا يحلل النسب. لا تُستخدم نسبة الاستبيان لتقرير الأبوة أو النسب أو لإجراء تشخيص نفسي.

## المتطلبات
- JDK 17
- Gradle 8.9
- Android SDK Platform 35
- اتصال بالإنترنت أثناء أول بناء لتنزيل مكتبات AndroidX CameraX وGoogle ML Kit وخط IBM Plex Sans Arabic.

## البناء والاختبار
من جذر المشروع:
```bash
gradle testDebugUnitTest
gradle assembleDebug
```

ملف APK المتوقع:
`app/build/outputs/apk/debug/app-debug.apk`

## GitHub Actions
يوجد سير العمل في `.github/workflows/android-build.yml` لتشغيل اختبارات الوحدة، وبناء APK من نوع debug، ورفعه كـ Artifact.

## الخط العربي
تنزّل مهمة Gradle الأوزان Regular وMedium وSemiBold وBold من مستودع `googlefonts/plex` الرسمي وتحفظ ترخيص SIL Open Font License داخل أصول التطبيق قبل معالجة موارد Android.
