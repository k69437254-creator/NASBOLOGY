# نسبولوجي | NASBOLOGY

تطبيق Android عربي بواجهة داكنة ولمسات بنفسجية، يبدأ بشاشة الترحيب ثم ينتقل خلال مراحل التحقق البايومتري الترفيهية، وفحص الوجه بالكاميرا الأمامية لمدة 8 ثوانٍ، ثم استبيان من 20 سؤالًا قابلًا للتعديل.

## المراحل والميزات
- شاشة ترحيب بالنص المتفق عليه وزر «أنا جاهز»؛ لا يظهر تنبيه في شاشة الترحيب نفسها.
- استخدام نافذة Android BiometricPrompt للتحقق من وجود وسيلة بيومترية مسجلة على الجهاز. التطبيق لا يستقبل بيانات البصمة نفسها ولا يخزنها.
- مرحلة فحص بصري متحرك، ثم نتيجة ترفيهية واحدة من نتيجتين مخزنة محليًا في DataStore لتظل نفسها عند إعادة الفحص على تثبيت التطبيق نفسه.
- فحص حي للوجه عبر CameraX مع اكتشاف وجود وجه محليًا عبر ML Kit لمدة 8 ثوانٍ. لا تُلتقط صورة ثابتة ولا تُحفظ صور الوجه في التطبيق. يمكن متابعة الاختبار عند رفض إذن الكاميرا.
- 20 سؤالًا أوليًا جاهزًا، بما فيها السؤال السادس «هل أنت دائماً قوي وواثق؟». جميع الأسئلة والاستنتاجات قابلة للتعديل من التطبيق، وتُحفظ على الجهاز.
- لكل سؤال استنتاجان قابلان للتعديل: واحد لإجابة «نعم» وآخر لإجابة «لا»؛ وفي النهاية يظهر تقرير الإجابات والاستنتاجات.
- صفحة مطوّر باسم Aram Aoyal مع زر يفتح حساب Telegram دون عرض الرابط كنص.
- دعم العربية واتجاه RTL، ألوان داكنة وبنفسجية، مؤثرات حركة، مشاركة التقرير، خيار صوت، وحفظ محلي اختياري لآخر تقرير.
- النصوص العادية غير قابلة للتحديد داخل الواجهة؛ حقول التحرير تبقى قابلة للتحديد حتى يتمكن المستخدم من تعديل محتواها.

## ملاحظة مهمة
كل نتيجة تتعلق بالنسب أو الأبوة داخل التطبيق عشوائية وترفيهية وليست استنتاجًا علميًا. لا يمكن للبصمة أو شكل الوجه أو إجابات الاستبيان إثبات النسب أو نفيه. اكتشاف الوجه يُستخدم فقط للتحقق من ظهور وجه أمام الكاميرا أثناء المسح.

## المتطلبات
- JDK 17
- Gradle 8.9
- Android SDK Platform 35
- اتصال بالإنترنت أثناء أول بناء لتنزيل مكتبات AndroidX CameraX وGoogle ML Kit.

## البناء والاختبار
من مجلد المشروع:
```bash
gradle testDebugUnitTest
gradle assembleDebug
```

ملف APK المتوقع:
`app/build/outputs/apk/debug/app-debug.apk`

## GitHub Actions
يوجد سير العمل في `.github/workflows/android-build.yml` لتشغيل اختبارات الوحدة، وبناء APK من نوع debug، ورفعه كـ Artifact.


## الخط العربي
- يستخدم التطبيق خط IBM Plex Sans Arabic محليًا عبر موارد Android.
- قبل معالجة موارد التطبيق، تنزّل مهمة Gradle الأوزان Regular وMedium وSemiBold وBold من مستودع `googlefonts/plex` الرسمي وتحفظ ترخيص SIL Open Font License داخل أصول التطبيق. يتطلب البناء الأول اتصالًا بالإنترنت.
- قائمة الأسئلة الأولية الحالية موجودة في `QUESTION_BANK.md`.
